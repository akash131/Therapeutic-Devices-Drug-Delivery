# Device Selection and Buying Guide

A comprehensive guide for healthcare organizations and professionals to evaluate, select, and procure therapeutic medical devices.

## Selection Framework

### Phase 1: Needs Assessment

#### Clinical Requirements Analysis
```
Assessment Checklist:
├── Patient Population
│   ├── Demographics (age, conditions)
│   ├── Volume (annual cases)
│   ├── Acuity levels
│   └── Special needs (pediatric, bariatric)
├── Clinical Outcomes
│   ├── Target outcomes
│   ├── Current gaps
│   ├── Quality metrics
│   └── Safety priorities
├── Workflow Integration
│   ├── Current processes
│   ├── Staff capabilities
│   ├── Space constraints
│   └── Time requirements
└── Strategic Alignment
    ├── Service line growth
    ├── Competitive positioning
    └── Technology roadmap
```

## Device-Specific Selection Criteria

### Drug Delivery Systems

#### Insulin Pumps
| Criterion | Priority | Evaluation Questions |
|-----------|----------|---------------------|
| CGM integration | Critical | Which CGM systems compatible? |
| Closed-loop capability | High | Automation level? Algorithm performance? |
| User interface | High | Patient tech comfort required? |
| Size/wearability | High | Tubed vs. tubeless preference? |
| Water resistance | Medium | Lifestyle requirements? |
| Cost model | High | Pump + supplies + CGM total? |
| Insurance coverage | Critical | Payer contracts in place? |

**Key Questions for Vendors:**
1. What is the real-world TIR (Time in Range) data?
2. How often are software updates released?
3. What training/support is provided to patients?
4. What is the supply chain reliability?

#### Infusion Pumps
| Criterion | Priority | Evaluation Questions |
|-----------|----------|---------------------|
| Drug library | Critical | Number of drugs? Customization? |
| EMR integration | Critical | Bidirectional capability? |
| Safety features | Critical | DERS, alarms, free-flow prevention |
| Wireless updates | High | Remote library updates? |
| Battery life | High | Backup power duration? |
| Ergonomics | Medium | Weight, pole mounting, portability |
| Channel configuration | Medium | Single, dual, multi-channel needs? |

**TCO Calculation:**
```
Total Cost of Ownership (5-year):
├── Capital acquisition
├── Consumables (IV sets, syringes)
├── Software licensing
├── Training (initial + ongoing)
├── Maintenance contracts
├── Integration costs
├── Upgrade costs
└── Decommissioning
```

## Procurement Process

### RFP Development

#### Essential RFP Sections
1. **Executive Summary**
   - Organization overview
   - Project scope and objectives
   - Timeline requirements

2. **Technical Requirements**
   - Functional specifications
   - Performance criteria
   - Integration requirements
   - Regulatory compliance

3. **Service Requirements**
   - Implementation support
   - Training programs
   - Warranty terms
   - Ongoing maintenance

4. **Commercial Terms**
   - Pricing structure
   - Payment terms
   - Contract duration
   - Volume commitments

5. **Vendor Qualifications**
   - Company background
   - Financial stability
   - References
   - Quality certifications

#### Evaluation Scoring
```
Scoring Methodology:
├── Technical Score (40%)
│   ├── Feature compliance
│   ├── Performance specifications
│   └── Integration capabilities
├── Clinical Score (25%)
│   ├── Clinical evidence
│   ├── User experience
│   └── Safety features
├── Service Score (20%)
│   ├── Implementation plan
│   ├── Training quality
│   └── Support responsiveness
└── Commercial Score (15%)
    ├── Total cost
    ├── Contract terms
    └── Value-adds
```

### Contract Negotiation

#### Key Contract Elements
| Element | Considerations |
|---------|----------------|
| Pricing | Base + consumables + service |
| Terms | Multi-year, escalation clauses |
| SLAs | Uptime, response times, penalties |
| Training | Initial + ongoing + refreshers |
| Updates | Software, hardware, included? |
| Warranty | Duration, coverage, extensions |
| Termination | Clauses, data portability |
| Liability | Limits, indemnification |

#### Negotiation Strategies
- Leverage GPO contracts
- Bundle purchases across departments
- Commit to volume for discounts
- Trade extended terms for pricing
- Include technology refresh provisions
- Negotiate cap on consumable increases

```
Implementation Timeline:
Phase 1: Preparation (Weeks 1-4)

├── Staff identification
└── Training scheduling

├── Equipment delivery

└── Testing and validation
```

## Total Cost of Ownership Models

### Capital Equipment TCO
```
TCO Calculator (5-Year):

Year 0 (Acquisition):
├── Purchase price/lease initiation
├── Installation costs
├── Integration expenses
├── Initial training
└── Facilities modification

Years 1-5 (Operations):
├── Consumables (annual)
├── Service contracts
├── Software licensing
├── Ongoing training
├── Staff time
└── Downtime costs

Year 5 (End of Life):
├── Decommissioning
├── Data migration
└── Disposal/trade-in
```

### Per-Procedure Cost Model
```
Procedure Cost Analysis:

Fixed Costs (per case allocation):
├── Equipment depreciation
├── Service contract
└── Software licensing

Variable Costs (per case actual):
├── Consumables
├── Disposables
└── Energy/utilities

Total Procedure Cost = Fixed + Variable
Break-even Volume = Fixed Costs / (Revenue - Variable Cost)
```

## Vendor Due Diligence

### Financial Assessment
- Annual reports and 10-K filings
- Credit ratings
- Market capitalization trends
- R&D investment levels
- Debt ratios

### Quality Assessment
- FDA inspection history
- Warning letters and recalls
- ISO certifications
- Quality metrics (DPPM, complaint rates)

### Reference Checks
```
Reference Questions:
1. How long have you used this product?
2. What was the implementation experience?
3. How responsive is technical support?
4. What are the product strengths/weaknesses?
5. What would you do differently?
6. Would you purchase again?
```

### Site Visits
- Observe actual clinical use
- Interview end-users
- Review performance data
- Assess integration quality
- Evaluate vendor relationship
